# 💧 Controle de Níveis de Água

## 📌 Sobre o projeto

Este projeto foi desenvolvido para a atividade da Agenda 11 de Desenvolvimento de Sistemas I. Ele simula o monitoramento do nível de água de um reservatório, mostrando mensagens coloridas no terminal conforme a situação identificada.

## 🎯 Objetivo

Criar um programa em Python que represente cinco níveis de água, usando mensagens e núcleos separados para facilitar a identificação de cada situação do reservatório, tudo no contexto do programa.

## 💧 Níveis do reservatório

| Nível | Situação | Cor |
|---|---|---|
| 1 | Muito baixo (crítico) | 🔴 Vermelho |
| 2 | Baixo | 🟡 Amarelo |
| 3 | Médio | 🟢 Verde |
| 4 | Alto | 🩵 Ciano |
| 5 | Muito alto (alerta) | 🔵 Azul |

## ⚙️ Funcionamento

O programa armazena mensagens dos cinco níveis em uma lista. Uma função verifica o nível informado no código e deve ser correspondente.
Em seguida, o programa exibe no terminal o nível atual do reservatório e a mensagemm colorida correspondnete. O nível pode ser alterado diretamente no código para testar as diferentes situações.
Para utlizar o programa, é necessário instalar a bib lioteca Colorama com o comendo:

```bash
pip install colorama
```

Depois, basta executar o arquivo `app.py`:

```bash
python app.py
```

## ✅ Conclusão

Com esta atividade, pratiquei o uso de listas, funções, estruturas condicionais e bibliotecas em Python. Também aprendi a utilizar a biblioteca Colorama para destacar mensagens com cores no terminal, tornando a visualização dos níveis do reservatório mais clara e organizada.
